# AIM Chess Academy Website

Modern, responsive web application for **AIM Chess Academy** built with Next.js (App Router), TypeScript, Tailwind CSS, and Next-Intl.

## 🚀 Key Features

- **Interactive Course Hub**: Beginner, Intermediate, Advanced, FIDE Rating, and 1-on-1 Masterclasses with international currency switcher.
- **Visual Curriculum & Student Progress**: Core chess skills roadmap (Openings, Tactics, Strategy, Calculation, Endgames, Game Analysis).
- **Categorized FAQ Explorer**: Instant live search and category pill filtering with 25+ comprehensive questions.
- **Student Achievements Showcase**: 1-card-per-row full-width tournament records with FIDE rating gains and coach assessments.
- **Chess Blog & Guides**: In-depth strategy articles with dynamic slug routing and sticky table of contents.
- **Photo Gallery & Trophy Room**: High-resolution image showcase with category filters and lightbox view.
- **Interactive Chess Board & Demo Booking**: One-click free demo assessment modal with WhatsApp & direct phone integration.

## 🛠️ Tech Stack


- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS / Vanilla CSS (Neo-Brutalist Sports Branding)
- **Internationalization**: next-intl
- **Icons**: Lucide React
- **Database / Backend**: Prisma, NextAuth

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
